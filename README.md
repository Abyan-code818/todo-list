# ✅ My To-Do List

A simple and responsive To-Do List website built with HTML, CSS, and vanilla JavaScript.

This project allows users to manage their daily tasks through a clean and minimal interface. It was created as part of my journey to learn front-end web development and practice building interactive websites.

## ✨ Features

- ➕ **Add Tasks** — Create new tasks by typing a task name.
- ✅ **Complete Tasks** — Mark tasks as completed using checkboxes.
- 🗑️ **Delete Tasks** — Remove tasks that are no longer needed.
- 📊 **Task Counter** — Track the number of remaining tasks.
- 💾 **Local Storage** — Automatically save tasks in the browser so they remain available after refreshing the page.
- ⌨️ **Enter Key Support** — Add tasks by pressing Enter.
- 📱 **Responsive Design** — Adapt the layout to smaller screens.
- 🎨 **Clean User Interface** — Minimal design with smooth transitions and simple animations.

## 🛠️ Built With

No additional libraries or frameworks are required to run this project.

   ```bash

   ```

2. Navigate to the project folder:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```
